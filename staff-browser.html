Staff browser

For Claire and the Every Star Learning team. Enable this once in every browser used for checking the website, including Safari on iPhone and any separate Chrome profiles.

Checking this browser’s setting…

Staff mode prevents Google Analytics visits and Etsy clicks from this browser. It does not change customer access or the website. This setup page itself never sends analytics.

The setting belongs to this browser on this device; it does not sync to other devices and is lost if browser storage is cleared. Private browsing needs its own setting each time. No IP address is needed.
